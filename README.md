# ActTrident releases

This repository holds **ActTrident desktop installers and update files only**. It contains no
source code.

- Installed copies of ActTrident (1.1.0 and later) check here for updates and install them.
- Releases are published automatically by ActTrident's release pipeline. Nobody pushes here by hand.
- Prereleases (`-beta`) are for the ActTrident team; only copies on the beta channel install them.

To install ActTrident, download `ActTrident-Setup-<version>.exe` from the latest release.
